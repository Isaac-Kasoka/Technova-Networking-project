# TechNova Ltd. Networking Project

## Overview

This was my first practical networking project, completed using Cisco Packet Tracer to develop my technical understanding as a GRC analyst.

I built a simulated network connecting TechNova Ltd.’s IT, Sales and HR departments through departmental switches and one shared router. The project covered IP addressing, DHCP, shared HTTP and FTP services, and an access control list restricting Sales-to-IT ICMP traffic.

## Key takeaways

- Understanding how devices communicate within and between subnets.
- Testing access restrictions alongside required business services.
- Recognising that blocking ping does not block every type of access.
- Using configuration and test evidence to assess a control’s scope and limitations.

**Tools used:** Cisco Packet Tracer, Cisco IOS CLI and Microsoft Word.
